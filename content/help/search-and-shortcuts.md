# Search and shortcuts

## Search

The **Search** page (the magnifier in the sidebar, or the tab bar on a phone)
looks through every flashcard, quiz question, summary section and ebook
chapter at once. It forgives typos, so "mitocondria" still finds
mitochondria.

- Use the **type** chips (Flashcards, Quizzes, Summaries, Ebooks) to show one
  kind of result, and the **subject** chips to narrow to one subject.
- A flashcard or quiz result opens its deck or quiz; a summary or ebook result
  opens that summary or chapter.
- Past-paper exam questions are not searchable, by design.

## The command palette

Press <kbd>Ctrl</kbd> + <kbd>K</kbd> (<kbd>⌘</kbd> + <kbd>K</kbd> on a Mac)
anywhere. Type part of a page or subject name and press <kbd>Enter</kbd>. With
nothing typed it lists the main pages. It also finds these help pages: try
"help streak".

## Keyboard shortcuts

| Where | Keys |
| --- | --- |
| Anywhere | <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>K</kbd>: command palette |
| Anywhere (desktop) | <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>\\</kbd>: collapse or expand the sidebar |
| Flashcards | <kbd>Space</kbd> or <kbd>Enter</kbd>: flip · <kbd>1</kbd>–<kbd>5</kbd>: grade (Blackout → Easy) |

| Image occlusion | <kbd>Shift</kbd> + <kbd>←</kbd> <kbd>→</kbd> or <kbd>[</kbd> <kbd>]</kbd>: previous/next figure |
| Image occlusion | <kbd>G</kbd>: gallery · <kbd>A</kbd>: show all labels · <kbd>H</kbd>: hide all / one · <kbd>Z</kbd>: zoom · <kbd>U</kbd> or <kbd>Ctrl</kbd> + <kbd>Z</kbd>: undo |

| Exam | <kbd>A</kbd>–<kbd>E</kbd> or <kbd>1</kbd>–<kbd>5</kbd>: answer · <kbd>←</kbd> <kbd>→</kbd>: previous/next question |

On a phone, swipe left and right in image occlusion to move between labels.

## The sidebar

On a computer, the sidebar can shrink to a row of icons to give pages like the
ebook reader more room: use the button at its edge or <kbd>Ctrl</kbd> +
<kbd>\\</kbd>. The app remembers your choice.
